Job Title: AI Engineer

We are looking for an AI Engineer to join our team, building and deploying
machine learning and generative AI features into production systems.

Requirements:
- 0 to 1 years of general software or AI-related experience (coursework,
  personal projects, or internships all count).
- Python.
- Machine Learning.
- Deep Learning.
- Bachelor's degree in Computer Science, Data Science, AI, or a related
  field.
- Familiarity with Git is preferred.
- Exposure to any deep learning framework (PyTorch or TensorFlow) is
  preferred but not required.
- Prior personal or academic project involving AI/ML is preferred.

Compensation: $70,000 USD annually.

Responsibilities:
- Build, train, and evaluate machine learning models.
- Integrate LLM-based features into existing backend services.
- Write clean, well-tested Python code.
- Collaborate with senior engineers on production ML practices.
